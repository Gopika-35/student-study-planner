# Student Study Planner 

A simple Python-based study planner designed to help students organize and manage their daily study tasks.

## Features

- Add new study tasks
- Set deadlines
- Set task priority
- View all tasks
- Mark tasks as completed
- Delete tasks
- Save tasks using JSON file storage

## Technologies Used

- Python
- JSON
- File Handling

## How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

```bash
python main.py
```

5. Follow the menu displayed in the terminal.
